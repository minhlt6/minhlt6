## 💡 Things I've been working on

### 📚 Academic Regulations RAG Chatbot

A question-answering system for university academic regulations, with context filtering by academic year.

- Combines **vector search and BM25** with Reciprocal Rank Fusion and a **Cross-Encoder reranker**.
- Synchronizes data between **Supabase and Qdrant**.
- Supports **SSE streaming** and conversation history using PostgreSQL and `asyncpg`.

`FastAPI` · `Qdrant` · `Supabase` · `PostgreSQL` · `LLMs`

### 👁️ Image Retrieval with Deep Metric Learning

Exploring a hybrid **ResNet-GT** architecture for fine-grained image retrieval, combining visual features with graph structure.

- Incorporates shortest-path distances from a **K-NN graph** into multi-head self-attention.
- Investigates **zero-shot retrieval** on the CUB-200-2011 dataset.

`PyTorch` · `ResNet50` · `Graphormer` · `Deep Metric Learning`
